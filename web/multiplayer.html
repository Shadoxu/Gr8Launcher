WISC / MULTIPLAYER

Meet in the same world.

Connect from Minecraft’s Multiplayer screen using a compatible profile and the server’s account requirements.

Before you join

  1. Ask the server for its address, Minecraft version, loader, and required modpack.
  2. Create or select a matching Wisc profile and install its required files.
  3. Launch Minecraft, open Multiplayer → Add Server, and enter the address.

Account compatibility

Wisc currently offers offline usernames and Ely.by accounts. Servers requiring Microsoft / Mojang account authentication may reject these sessions. Check the server’s rules and authentication requirements before joining.

Troubleshoot a connection

Version errors usually need a matching game or modpack version. For an invalid session, reauthenticate with your account provider and check the server’s account support. For a timeout, verify the address, network connection, server availability, and firewall settings.
