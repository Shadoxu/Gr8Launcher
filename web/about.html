WISC / ABOUT

Small launcher. Clear purpose.

Wisc is a free, open-source Minecraft Java Edition launcher built with Python and Flet.

Room for your game

Keep versions, instances, mods, skins, and launch options in one desktop interface. The project retains its Minecraft-inspired top navigation, library shelf, and selectable themes.

Open by design

Source code is available under GNU GPL v3. You can inspect it, build it, report bugs, and contribute improvements. Some packaged files retain the earlier Gr8Launcher name.

Explore the repository ↗

An independent project

Wisc is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft. Minecraft and provider services have their own account, license, and usage requirements.
