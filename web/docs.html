Where your data lives

Launcher settings, profiles, and skin caches live in gr8launcher inside Minecraft’s default directory. Separate game instances live in the Minecraft directory’s instances folder unless a profile points to an existing game folder.

SystemLauncher data
Windows%APPDATA%\.minecraft\gr8launcher
Linux~/.minecraft/gr8launcher
macOS~/Library/Application Support/minecraft/gr8launcher

Back up worlds and instance folders before reinstalling or making large mod changes. Ely.by credentials use native credential storage when available, with a session-only fallback.

Launcher updates

Use Options → Updates to check published versions and release notes. Download the correct package from Downloads when updating manually.
