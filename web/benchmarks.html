WISC / BENCHMARKS

Measure your own setup.

Compare your own runs under consistent conditions. This project does not publish verified FPS or launch-speed claims.

Make a fair comparison

  1. Use the same Minecraft version, loader, mods, Java runtime, RAM allocation, and game settings.
  2. Separate the first installation from later launches. Record launch time consistently, for example from Play to the title screen.
  3. For FPS, use the same world, location, resolution, render distance, and warm-up time.
  4. Take at least three measurements and compare averages. Record hardware and any background workload.
