WISC / PRIVACY

Your data, explained.

How this website, the desktop launcher, and linked services handle information.

On this website

The site has no account sign-in, advertising scripts, or added analytics. Hosting providers may process request information such as IP addresses and access logs to deliver the site. Google Fonts supplies the typefaces, so your browser contacts Google’s font services. GitHub receives requests when you view releases or source links.

The release API retrieves public release metadata from GitHub. Do not send credentials or personal data to this endpoint. The launch doctor uses your answers in the current page without storing or uploading them.

Benchmark storage

Wisc Bench saves the measurements you enter in this browser’s local storage, when available. Use Clear runs in the notebook or clear this site’s browser data to remove them. CSV exports stay on your device unless you choose to share them.

In the desktop launcher

Settings, profiles, game folders, and cached skins are stored on your computer. Ely.by sessions use native credential storage when available, and fall back to memory-only sessions when native storage fails. Game logs are redacted by the launcher before display or export; review logs before sharing them.

Downloads, account authentication, skin sync, and mod searches contact the services you use, including Minecraft distribution hosts, Ely.by, Modrinth, CurseForge, and GitHub. Optional Discord Rich Presence shares activity with Discord when enabled in Options.

Service policies and questions

External services apply their own privacy policies, including Vercel, Google, and GitHub. For questions about project behavior, use GitHub issues without posting personal or secret information.
